# Rúbrica — Lab Extra SSRF (sobre 100 puntos)

| Criterio | Puntos |
|---|---|
| **Cadena de explotación documentada.** Los 3 retos con razonamiento + comandos + salidas. No alcanza la flag: hay que mostrar el camino. | 30 |
| **P1–P2 (modelo de confianza + oráculo de escaneo).** Entiende *por qué* funciona el ataque y cómo los errores se convierten en información. | 20 |
| **P3 (hallazgo profesional).** Activo, vector, impacto, evidencia — redacción de informe, no de apunte. | 15 |
| **P4 (mitigaciones).** Tres mitigaciones ordenadas, con las limitaciones de cada una. Bonus si menciona por qué el filtrado de strings no alcanza. | 20 |
| **P5 (conexión cloud).** Metadata service explicado con precisión. | 5 |
| **Research.** Caso real o metadata service, con fuentes citadas. | 10 |

## Reglas

- **Inventar evidencia es causal de rechazo.** "No pude resolver el R3" con el
  análisis bien hecho vale más que una flag sin camino.
- Las flags solas no suman: son la constancia de que pudiste. El informe es la
  nota.
- La declaración de uso de IA es obligatoria. No declararla = entrega incompleta.
