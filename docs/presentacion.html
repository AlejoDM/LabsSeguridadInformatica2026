// Qué es

No se aprende leyendo.
Se aprende haciendo.

Un recorrido práctico y progresivo por la seguridad ofensiva. Operás herramientas reales contra objetivos deliberadamente vulnerables que se levantan solos en Docker, dentro de tu propia máquina.

Hands-on

Todo con código

Cada técnica se ejecuta a mano, tool por tool, clasificando y explicando cada escenario.

Autodescubrible

Se levanta solo

Un comando ./ctf y el entorno arranca. Cero instalar en tu máquina.

Progresivo

Sube de nivel

De tools básicas a pentest profundo con agentes de IA. La dificultad crece lab a lab.

// Filosofía

Cuatro reglas que no se negocian

01

Conceptos antes que código

Primero entendés el porqué; después tocás la herramienta. Sin fundamentos, un scanner es ruido.

02

A mano antes que automático

Recon, explotación y post — todo manual primero. Los agentes recién al final.

03

La IA es una herramienta

El agente acelera; no reemplaza tu criterio. El humano dirige, la máquina ejecuta.

04

Sin atajos

El aprendizaje real lleva esfuerzo y tiempo. Nadie se hace pentester en dos horas.

Reconocimiento

Antes de tocar nada, entendé qué hay. Un puerto abierto no es un hallazgo; un puerto identificado y clasificado sí.

  • Barrido de puertos y detección de versiones
  • Banner grabbing y fingerprinting de servicios
  • Clasificar contra CVE / CVSS

// Cómo se entrega y se corrige

Como en un proyecto real

Flujo
  • fork + PR El mismo flujo con el que se colabora en software serio.
  • grupos 4–5 En entregas/labNN/grupoXX/.
  • historial Los commits de todos cuentan para la nota.
Evaluación
  • rúbrica 100 Con descriptores y causales de rechazo.
  • flags · informe Las flags demuestran que pudiste; el informe, que entendiste.
  • IA declarada Usarla no está prohibido; no declararla, sí.

⚠ Uso responsable. Todo se practica solo contra los contenedores de la cátedra. Estas técnicas contra terceros son delito — Ley 26.388.

// Bajo el capó · para la cátedra

El motor

Reproducible

Docker Compose

Mismo lab en cualquier SO. Se destruye y se recrea. Los targets no se exponen al host.

Verificable

Flags por SHA-256

El manifest guarda hashes, nunca la flag en claro. ./ctf submit compara.

Extensible

Plantilla

Un lab nuevo es copiar labs/_plantilla y rellenar. El número se deriva solo.

Cada lab: README (teoría→ejemplos→tools→práctica) · entorno/ Docker · retos.manifest · rúbrica · solucion.md (solo docente).
