// Unidades 01–04 · fundamentos en código

Antes de atacar, entender

01 · CIA

¿Qué protegés?

Confidencialidad, integridad, disponibilidad. Verificación de integridad con hashes.

02 · Cripto

Cómo (no) se usa

Rompés un cifrado clásico por frecuencia; construís una MAC con HMAC.

03 · Auth

¿Sos quien decís?

Contraseñas con PBKDF2 y salt; segundo factor TOTP, todo verificado contra el RFC.

04 · Gestión

Decidir con números

ISO 27001 / NIST CSF y riesgo cuantitativo: priorizar por ALE, no por corazonada.

Python, biblioteca estándar. Nada de "instalar y que ande": entender y construir.

// ★ Práctico Final

El engagement completo

Un solo objetivo que exige encadenar TODO el curso: recon → foothold por SQLi → loot de un token → RCE hasta los datos de clientes. Sin guía paso a paso: para eso hiciste los diez labs.

El desafío

Caja negra. Cuatro hitos encadenados. Reglas de engagement como en un pentest real.

El entregable

Un informe de pentest profesional: resumen ejecutivo + hallazgos con CVSS, evidencia y remediación.

La técnica se demuestra rompiendo; el valor profesional, comunicando lo que rompiste de forma que alguien lo arregle.

// Cómo se entrega y se corrige

Como en un proyecto real

Flujo
  • fork + PR El mismo flujo con el que se colabora en software serio.
  • grupos 4–5 En entregas/labNN/grupoXX/.
  • historial Los commits de todos cuentan para la nota.
Evaluación
  • rúbrica 100 Con descriptores y causales de rechazo.
  • flags · informe Las flags demuestran que pudiste; el informe, que entendiste.
  • IA declarada Usarla no está prohibido; no declararla, sí.

⚠ Uso responsable. Todo se practica solo contra los contenedores de la cátedra. Estas técnicas contra terceros son delito — Ley 26.388.

// Bajo el capó · para la cátedra

El motor

Reproducible

Docker Compose

Mismo lab en cualquier SO. Se destruye y se recrea. Los targets no se exponen al host.

Verificable

Flags por SHA-256

El manifest guarda hashes, nunca la flag en claro. ./ctf submit compara.

Extensible

Plantilla

Un lab nuevo es copiar labs/_plantilla y rellenar. El número se deriva solo.

Cada lab: README (teoría→ejemplos→tools→práctica) · entorno/ Docker · retos.manifest · rúbrica · solucion.md (solo docente).
